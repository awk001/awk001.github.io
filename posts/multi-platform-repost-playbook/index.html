一份母稿（博客 Hexo Markdown）吃遍天，平台差异化微调，原创声明 + 原文链接回流。 本文是给「光眸笔记」文章做多平台分发的可执行 SOP，覆盖公众号、朋友圈、今日头条、小红书、B站、抖音。

0. 核心原则

  1. 母稿唯一：所有内容以博客 Hexo Markdown 为源头，不各平台分开写。
  2. 差异化微调，禁止原样复制：全平台一字不差地发，会触发平台查重机制，导致流量下跌、账号降权。每个平台至少改标题、摘要、开头 2 句、封面。
  3. 原创声明 + 回流：每篇在各平台文末/评论区置顶原文链接，把外部流量引回博客（沉淀私域、利于 SEO）。
  4. 本人实名账号：所有平台用自己实名注册的账号，不碰未授权账号。

1. 平台矩阵与内容形态映射

平台 内容形态 推荐工具 半自动环节 关键注意
微信公众号 长文图文 OpenWrite / mdnice 一键扩散 不放外链，用「阅读原文」或评论区置顶；朋友圈转发卡片
微信朋友圈 短链卡片 手动 — 摘金句 + 博客短链

2. 工具链落地（半自动）

2.1 图文主力：OpenWrite（公众号 + 头条）

  • 安装 Chrome 插件，官网 openwrite.cn，当前版本 v2.1.24（2026-08 仍在更新）。
  • 绑定「微信公众号」「今日头条」账号（微信扫码授权，安全）。
  • 把博客 Markdown 粘贴进编辑器 → 点「发布」→ 勾选平台 → 各平台编辑器确认即发。
  • 图片自动转平台图床，不会变小红叉。免费版够个人用。

2.2 小红书：MD2Card（出图）

  • 完全免费、无水印、不用登录。把文章核心段落整理成 Markdown，选模板生成 3–6 张长图，导出 PNG。
  • 配一句小红书风格标题 + 话题标签，手动发布。
  • 备选：流光卡片（免费版带 AI 文案润色）。

2.3 视频平台：蚁小二 + 剪映

  • 蚁小二支持抖音 / 快手 / 小红书 / 视频号 / B站 / 公众号等 40+ 平台，图文+短视频一键发、定时发布、CLI 自动发、AI 视频创作（免费 + 订阅）。
  • 博客纯文字 → 视频的缺口在「脚本」：用豆包 / 通义 / Claude 把文章改成口播稿或分镜，再用剪映「图文成片」或蚁小二 AI 视频生成成片，真人配音/字幕提升原创度。

3. 标准转载 SOP（每篇 7 步）

  1. 母稿定稿：博客 Hexo 写好，含 cover、规范 front-matter。
  2. 拆平台变体：准备 N 个标题变体、每平台独立摘要、封面文案（差异化，别复制）。
  3. 图文平台：OpenWrite 一键扩散到公众号 + 头条，进各编辑器微调后发布。
  4. 小红书：MD2Card 出 3–6 图 + 小红书风格文案，手动发，挂话题。
  5. 视频平台：AI 出口播稿 → 剪映 / 蚁小二成片 → 发 B站 / 抖音（前 3 秒钩子）。
  6. 朋友圈：摘金句 + 博客短链，卡片转发。
  7. 回填回流：各平台文末 / 评论区置顶原文链接；博客文末加「本文已同步发布于：公众号 / 小红书 / 头条 / B站 / 抖音，搜索 AWK」。

4. 排版 / 版权 / SEO 规范

  • 原创声明模板（每平台文末）：

    本文首发于「光眸笔记」博客，转载请注明出处。原文链接：https://awk001.github.io/posts/xxx/

  • 外链限制：公众号正文不放外链（会被吞），放「阅读原文」或评论区置顶；头条 / 小红书可带链接。
  • 图片图床：OpenWrite 自动转；小红书用本地导出图，不依赖外链。
  • 敏感词预检：发布前过一遍平台违禁词，避免审核卡住。
  • 错峰发布：不一次性全发，见下节奏。

5. 发布节奏与数据回收

  • 节奏：博客首发 → 24h 内发图文平台（公众号 + 头条）→ 48h 内发小红书 + 视频（B站 / 抖音）→ 同步朋友圈。
  • 数据回收：蚁小二后台 / 各平台创作者中心，每周复盘曝光、互动、涨粉、回流点击，汰弱留强。

6. 风险与避坑

  • ❌ 禁止全平台原样复制（查重降权，最常见雷区）。
  • ❌ 公众号正文塞外链（被系统吞，改用阅读原文 / 评论区）。
  • ❌ 视频平台纯 AI 成片无真人元素（原创度低，易被限流；加配音 / 字幕 / 实拍补原创度）。
  • ❌ 用非本人实名账号（双重风控处罚）。

7. 下一步行动清单

  • 确认 6 个平台账号均已注册且本人实名。
  • 安装 OpenWrite 插件、MD2Card、蚁小二客户端。
  • 选 1 篇博客（建议「工业视觉壁垒」或「Twikoo 免费部署」）做试点，跑通整条 SOP。
  • 试点后看数据，再决定是否全量铺开。

进阶：可在 Hexo 加一个注入脚本，渲染时自动在文末追加「本文已同步发布于…」声明块，省去每篇手填。需要时再开。
