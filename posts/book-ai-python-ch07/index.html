第 7 章是”综合篇”前的热身：用 Python + Matplotlib 把第 6 章的卷积过程画成动画/示意图，从视觉上吃透”滑动窗口”。

7.1 为什么要”画出来”

卷积对初学者最难的是”滑动”的动态感。文字描述偏静态，一旦用图把”窗口在哪、覆盖了哪些像素”画出来，理解立刻立体。

7.2 最简体验：画出当前窗口位置

复用第 6 章的数组，用 imshow 显示图像，再用矩形框标出当前卷积核的位置：

思考：把 ki, kj 放进 for 循环逐格移动，每步画一帧，就成了一个”卷积滑动”的动画——这正是原书示意图背后的做法。

7.3 把窗口与计算结果对照

每一格窗口算出的值，恰好是输出特征图 (i, j) 处的一个点。画图时可以把”输入窗口”和”输出点”并排显示，直观看到”局部 → 一个点”的映射。

7.4 巩固 Python 与 Matplotlib

这一章顺带把前面学的东西再练一遍：

  • for 循环遍历位置（第 3 章）
  • 数组切片取 patch（第 5 章）
  • imshow / Rectangle 可视化（第 4 章）

小结

“画出来”是理解动态算法的通用技巧。学会给卷积画滑动窗口，后面理解池化、转置卷积、注意力滑动窗口都会快很多。下一章进入真正的综合：读源码。
