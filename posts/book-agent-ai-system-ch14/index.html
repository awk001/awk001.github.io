第 14 章复现”DeepResearch”类 Agent：给定一个问题，它能自己检索、交叉验证、写出带引用的长篇研究报告。这是 RAG + 规划 + 反思的集大成者。

14.1 它和普通搜索的区别

  • 普通搜索：返回一堆链接，人自己读；
  • 深度研究 Agent：自己读、自己比、自己写，产出的是”结论 + 论据”。

14.3 为什么需要”交叉验证”

网络信息良莠不齐。深度研究 Agent 的关键能力之一是对同一事实从多个来源印证，并在引用不足时明确标注”存疑”。这直接呼应第 8 章 RAG 与第 12 章的”鲁棒性”。

14.4 实现要点

  • 检索策略：先广后深，先找权威源再补细节；
  • 引用可追溯：每句论断都挂来源，便于人审；
  • 长文管理：用第 9 章上下文工程，避免写到后半段忘了前半段；
  • 成本控制：检索与生成都很费 token，要设预算上限。

14.5 一个常见失败模式

模型”自信地总结了一篇它其实没真正读到的文章”。

防御手段：强制”先存证据再下结论”，且证据必须来自真实检索返回，而非模型脑补。

14.6 小结

深度研究 Agent 把”检索—验证—撰写—反思”串成闭环，是知识工作自动化的代表。下一章我们换个画风，让 Agent 住进一个”小镇”里——构建赛博小镇。
