第 4 章是”从 0 手搓 Agent”的真正起点。三个范式——ReAct、Plan-and-Solve、Reflection——几乎是所有现代 Agent 框架的内核，看懂它们，后面任何框架你都能一眼看穿。

4.1 范式一：ReAct（Reason + Act）

核心思想：把”思考（Thought）”和”行动（Action）”交替写进同一条提示里，让模型自己决定下一步是继续想还是调工具。

要点：ReAct 把”推理轨迹”显式留下来，既可观测、又可被纠正，是工程上最稳的基线范式。

4.2 范式二：Plan-and-Solve（先规划再执行）

ReAct 适合”走一步看一步”，但复杂任务容易走偏。Plan-and-Solve 先让模型生成完整计划，再逐步执行：

  1. 规划阶段：把任务拆成有序子目标；
  2. 执行阶段：逐个子目标推进，必要时回规划。

思考：这对应人类”先列待办、再逐项做”。多智能体里也常用一个”规划者”专门出计划。

4.3 范式三：Reflection（反思 / 自我批评）

让 Agent 在产出后自我评审，发现不足就迭代改进：

要点：Reflection 是”质量放大器”。很多 coding agent 的本质就是 Write → Run → Reflect 的循环。

4.4 三者如何组合

实际系统很少只用一个：

  • ReAct 做主循环（想一步、动一步）；
  • Plan-and-Solve 在任务入口做整体拆解；
  • Reflection 在关键节点做质量把关。
