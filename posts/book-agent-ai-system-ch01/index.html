第 1 章是整本书的”镜头校准”：在动手写任何代码之前，先统一我们对”什么是智能体”这件事的认知。后面所有范式、框架、案例，都是在这个定义上长出来的。

1.1 智能体是什么

一句话：智能体（Agent）是”能感知环境、自主决策、采取行动以达成目标”的系统。它和普通的”程序”最大的区别在于——

  • 自主性：无需每一步都等人下令，能自己决定下一步做什么；
  • 反应性：能感知环境变化并响应；
  • 目标导向：行为围绕一个目标展开，而不是死板的脚本；
  • 持续运行：在一个循环里反复”感知 → 思考 → 行动”。

要点：智能体不是”一个更聪明的函数”，而是一个”带记忆、能调用工具、会循环决策”的闭环系统。

1.2 智能体的典型类型

按能力边界，可以把常见智能体分成几类：

类型 特点 例子
反射型 刺激-响应，无内部状态 规则 Bot
基于目标 规划出达成目标的步骤 路径规划 Agent
基于效用 在多个目标间权衡取舍 推荐 / 调度 Agent
学习型 能从经验中改进策略 RL Agent
LLM 驱动型 由大模型做”思考中枢” ChatGPT / AutoGPT 类

1.3 智能体 vs. 普通程序

一个 helpful 的对比视角：

  • 普通程序：输入确定 → 执行确定逻辑 → 输出确定结果；
  • 智能体：给定目标 → 自己拆解 → 边做边看 → 中途可调整路径。

这也解释了为什么”工具调用（Tool Use）”和”记忆（Memory）”是智能体的两大基石：它得能动手（调用外部能力），还得记得住（跨步骤状态）。

1.4 几个最该先建立的心智模型

  1. Agent = LLM + 记忆 + 工具 + 循环。缺哪块都只是”半个”智能体。
  2. 上下文窗口就是它的”工作台”，所有思考都发生在这一段文本里。
  3. 它不一定是自治的——很多落地场景里，human-in-the-loop（人审一道）才是 production 的正确形态。

1.5 小结

第 1 章没有代码，但定下了全书的地基：智能体是一个闭环决策系统，大模型只是它的”大脑”，真正让它”能干活的”是工具与记忆。下一章我们从历史角度，看这个想法是怎么一步步走到今天的。
