为 Hexo + async 主题博客接入 Twikoo 评论系统

本博客（光眸笔记）用的是 Hexo 7 + async 主题，评论系统选的是 Twikoo。它免费、无广告、界面干净，和 imalun.com 用的是同一套。

但 Twikoo 需要一个后端环境来存评论数据，所以启用分两步：部署 Twikoo 后端 → 把环境 ID 填进博客配置。

一、部署 Twikoo 后端（推荐腾讯云 CloudBase）

方式 A：腾讯云 CloudBase（免费额度足够个人博客）

注意：不要直接在「腾讯云 SCF 独立云函数」页面创建函数，那样拿不到 Twikoo 需要的 envId。必须走 CloudBase（云开发）环境。

  1. 打开 腾讯云 CloudBase 控制台。
  2. 登录后点击「新建环境」，选一个离你近的地域（默认 ap-shanghai 即可）。
  3. 进入新建的环境 → 左侧「云函数」→「新建云函数」。
  4. 在创建页：
    • 函数类型：选 Web 函数（Twikoo 要接收 HTTP 请求）。
    • 函数名称：填 twikoo。
    • 运行环境：选 Nodejs 18 或更高，不要选 Python。
  5. 下载 Twikoo 云函数代码：
    • 到 Twikoo GitHub Releases 下载最新 twikoo-cloudbase.zip。
    • 解压后把全部文件作为云函数代码上传（或复制粘贴 index.js + package.json）。
  6. 点击「完成」部署云函数。
  7. 部署成功后，复制该 CloudBase 环境的 环境 ID（形如 env-xxxxxxxxxxxxxxxx），后面会用到。

如果你已经在 console.cloud.tencent.com/scf 这种页面，说明走错了入口。回到 tcb 控制台，从「环境」里进云函数。

方式 B：Vercel / Railway / 私有服务器

如果你更熟悉境外平台，可以用 Vercel 一键部署：

  1. Fork twikoo 仓库。
  2. 在 Vercel 导入该仓库，框架预设选 Other，构建命令留空，输出目录留空。
  3. 环境变量不需要额外设置。
  4. 部署后得到域名，如 https://twikoo-xxx.vercel.app。

这种方式得到的不是 envId，而是一个 URL。async 主题目前主要支持腾讯云 envId 形式。如果用 Vercel，需要手动改 themes/async/layout/_third-party/plugin.ejs 里的初始化参数，把 envId 换成 path: 'https://twikoo-xxx.vercel.app'。

三、构建并部署

等待 GitHub Pages 刷新（1–3 分钟），然后打开任意文章页，滚动到最底部，应该能看到 Twikoo 评论框。

四、管理员后台与通知

Twikoo 部署后，首次使用需要设置管理员密码：

  1. 打开带评论的文章页，按 Ctrl + Shift + K（或在评论框右下角找「管理」入口）。
  2. 设置管理员密码、邮箱。
  3. 在后台可以配置：
    • 评论审核（防垃圾）
    • 邮件通知（新评论推送到你的邮箱）
    • 反垃圾（Akismet、腾讯云验证码）
    • 微信/QQ/Telegram 推送

五、常见问题

现象 原因 处理
文章底部有一块空白区域，评论框没出来 envId 未填，或走错了 SCF 独立函数入口 必须拿到 CloudBase 的 env-xxx 环境 ID 并填入 _config.async.yml
评论区空白，控制台报 envId 错误 环境 ID 填错或未填 检查 _config.async.yml 的 envId
评论区显示「Twikoo 加载失败」 云函数未部署或地域不对 确认云函数状态为「运行中」，必要时填 region
提交评论后没反应 云函数返回错误 去腾讯云 CloudBase 日志里查看具体报错
本地预览看不到评论 Twikoo 需要真实域名 本地 localhost 可以正常显示，但部分功能受限；最终效果以公网为准

六、关键约定

  • 评论系统：Twikoo
  • 后端：腾讯云 CloudBase 云函数
  • 主题配置字段：_config.async.yml 的 comment.twikoo.envId
  • 文章开关：默认开启；单独关闭用 comments: false
  • 管理后台：Ctrl + Shift + K 或在评论框右下角进入

按上面步骤拿到 envId 并填好，博客就有了和 imalun 一样的评论功能。
