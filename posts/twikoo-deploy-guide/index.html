为 Hexo + async 主题博客接入 Twikoo 评论系统

本博客（光眸笔记）用的是 Hexo 7 + async 主题，评论系统选的是 Twikoo。它免费、无广告、界面干净，和 imalun.com 用的是同一套。

Twikoo 需要一个后端环境来存评论数据，所以启用分两步：部署 Twikoo 后端 → 把环境标识填进博客配置。

后端有两种选择：

  • Netlify + MongoDB Atlas（推荐，完全免费）：Twikoo 官方对免费方案支持最好的是 Netlify，国内访问速度不错。
  • 腾讯云 CloudBase（付费）：国内访问最快，但新环境必须买个人版（19.9 元/月）才能加跨域域名，免费体验版配不出来。

一、部署 Twikoo 后端

方式 A：Netlify + MongoDB Atlas（免费推荐）

1. 准备 MongoDB Atlas 数据库

  1. 打开 MongoDB Atlas 注册账号。
  2. 创建一个 免费的 M0 集群（512MB 足够个人博客）。
  3. 创建数据库用户，记下用户名和密码。
  4. 进入 Network Access（网络访问），添加 0.0.0.0/0（允许所有 IP 访问，因为 Netlify 函数出口 IP 不固定）。
  5. 点击集群的 Connect → Drivers，复制连接字符串，把 <db_password> 换成你的密码。

2. 部署 Twikoo 到 Netlify

  1. 打开 twikoojs/twikoo-netlify，点右上角 Fork，把仓库复制到你自己的 GitHub 账号。
  2. 打开 Netlify 控制台，Add new site → Import an existing project → Deploy with GitHub。
  3. 选择你刚才 fork 的 你的用户名/twikoo-netlify。
  4. 在部署配置页找到 Environment variables，添加：
    • Key：MONGODB_URI
    • Value：你复制的 MongoDB 连接字符串
    • 勾选 Contains secret values（保护密码）
    • Values 选 Production，粘贴连接字符串后保存
  5. 点 Deploy site，等状态变成 Published。
  6. 部署完成后，进入 Project configuration → General → Visitor access → Project visibility，把 Production visibility 和 Deploy Preview visibility 都改成 Public。否则外部访问会返回 401，评论框加载不出来。
  7. 点击站点链接测试，看到「Twikoo 云函数运行正常」即成功。

方式 B：Vercel + MongoDB Atlas（免费，国内体验一般）

步骤和 Netlify 类似，区别是：

  1. Fork twikoojs/twikoo 仓库。
  2. 在 Vercel 导入，框架预设选 Other，构建命令和输出目录都留空。
  3. 添加环境变量 MONGODB_URI。
  4. 进入 Settings → Deployment Protection，把 Vercel Authentication 设为 Disabled，否则前端调不到函数。
  5. 部署后得到的域名如 https://twikoo-xxx.vercel.app 就是 envId。

Vercel 默认域名 *.vercel.app 在中国大陆访问较慢，建议绑定自己的域名。

方式 C：腾讯云 CloudBase（需付费套餐）

重要：Twikoo 的 CloudBase 方案现在需要付费套餐（个人版 19.9 元/月起）。免费体验版无法添加「跨域域名」，评论框无法调用云函数，所以不花钱配不出来。

  1. 打开 腾讯云 CloudBase 控制台。
  2. 点击「新建环境」，购买时数据库请选「云数据库」，地域推荐 上海（ap-shanghai）。套餐选个人版即可。
  3. 进入新建的环境 →「身份认证 - 配置 - 登录方式」，启用 「允许匿名登入」。
  4. 进入「HTTP 网关 - 跨域设置 - 添加跨域域名」，添加你的网站域名：

三、构建并部署

等待 GitHub Pages 刷新（1–3 分钟），然后打开任意文章页，滚动到最底部，应该能看到 Twikoo 评论框。

四、管理员后台与通知

Twikoo 部署后，首次使用需要设置管理员密码：

  1. 打开带评论的文章页，按 Ctrl + Shift + K（或在评论框右下角找「管理」入口）。
  2. 设置管理员密码、邮箱。
  3. 在后台可以配置：
    • 评论审核（防垃圾）
    • 邮件通知（新评论推送到你的邮箱）
    • 反垃圾（Akismet、腾讯云验证码）
    • 微信/QQ/Telegram 推送

五、常见问题

现象 原因 处理
访问 Netlify 函数返回 401 / Login Redirect 站点可见性还是 Private Project configuration → General → Visitor access → 改成 Public
文章底部评论框空白，控制台报 envId 错误 envId 未填或填错 检查 _config.async.yml 的 envId，Netlify 必须是完整 URL
评论区显示「Twikoo 加载失败」 函数未部署、站点未公开、或 CORS 未配置 确认函数状态正常、Netlify visibility 为 Public、MongoDB 网络访问设为 0.0.0.0/0
CloudBase 底部空白且已填 envId 免费体验版无法添加跨域域名 升级个人版，或改用 Netlify 免费方案
GitHub Releases 里没有 twikoo-cloudbase.zip Twikoo 已改为在线 npm 安装 CloudBase 不需要下载任何文件，直接写 index.js + package.json
本地预览看不到评论 Twikoo 需要真实域名 本地 localhost 可以正常显示，但部分功能受限；最终效果以公网为准

六、关键约定

  • 评论系统：Twikoo
  • 免费后端推荐：Netlify + MongoDB Atlas
  • 付费后端备选：腾讯云 CloudBase 云函数
  • 主题配置字段：_config.async.yml 的 comment.twikoo.envId
  • envId 可以是 CloudBase 的 env-xxx，也可以是 Netlify/Vercel 的完整 URL
  • 文章开关：默认开启；单独关闭用 comments: false
  • 管理后台：Ctrl + Shift + K 或在评论框右下角进入

按上面步骤填好 envId，博客就有了和 imalun 一样的评论功能。
